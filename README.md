# AIRPORT.MANAGEMENT.SYSTEM

A simple Airport Management System developed using Python, with basic lists and dictionaries for storing and managing flight information.

The system allows users to add, view, search, and delete flights through a simple command-line menu. Each flight contains details such as flight number, source, destination, stoppage, arrival and departure time, fuel, passengers, and crew members.

🛠️ Technologies Used
Python 3
Lists
Dictionaries
Functions
Loops and Conditional Statements
▶️ How to Run
python airport_management.py

This project is created for learning and practicing basic Python programming and data management concepts.
